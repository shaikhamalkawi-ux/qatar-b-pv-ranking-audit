# Public-scope and confidentiality boundary

- Only OEDI PVDAQ 2107 derived daily data and OEDI audit scripts are included.
- Forbidden in this repository: Qatar raw telemetry, restricted analysis code/binaries and zipped source packages, confidential module/product/channel crosswalks, unpublished QEERI emails, institutional approvals, unpublished manuscript or figures containing owner-derived results.
- Review visibility does not imply approval to publicly release other components of the paper.
- Do **not** open a GitHub issue with any private owner data or emails.
- This archive supports **only** the public external OEDI replay, not the private Qatar results.
